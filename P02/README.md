# P02 Tipe dan Input: Tipe Data, Variabel, Konstanta, dan Input Dasar
## Isi
| Berkas | Kegunaan |
|---|---|
| `tipe_dasar.cpp` |Digunakan untuk mengenal dan mencoba beberapa tipe data dasar dalam C++, seperti `int`, `double`, `char`, `bool`, dan `string`. |
| `konstanta.cpp` | Digunakan untuk mempraktikkan penggunaan nilai tetap dengan `const` serta melihat apa yang terjadi jika nilai tersebut coba diubah. |
| `input_dasar.cpp` | Digunakan untuk latihan menerima data dari pengguna melalui keyboard menggunakan `cin` dan melihat perbedaan input satu kata dengan input yang memiliki spasi. |
| `sinilai_v01_awal.cpp` | Merupakan kode awal program SiNilai yang perlu dilengkapi agar dapat menerima dan menampilkan informasi mahasiswa dengan benar.|
| `contoh_masukan.txt` |Berisi data contoh yang dapat digunakan sebagai bahan pengujian program SiNilai tanpa harus memasukkan data secara manual. |
| `.vscode/`, `.gitignore` | Berisi pengaturan pendukung untuk proses pengembangan program di VS Code serta mengatur file yang tidak perlu dimasukkan ke repository. |
